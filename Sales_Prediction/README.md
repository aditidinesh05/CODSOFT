## 🧠 Project Overview

Sales prediction involves forecasting how much of a product customers are likely to purchase by analyzing factors such as advertising spend across different platforms.

In this project, historical advertising data is analyzed and a regression-based machine learning model is built to **predict future sales**. The project demonstrates how data science can directly support **business strategy and decision-making**.

---

## 🎯 Objectives

- Analyze advertising data and sales trends  
- Understand the relationship between marketing spend and sales  
- Build a regression model to predict sales  
- Evaluate model performance using standard metrics  
- Interpret results to derive business insights

## 🔍 Exploratory Data Analysis (EDA)

Exploratory Data Analysis was performed to:
- Understand the distribution of sales data  
- Identify correlations between advertising platforms and sales  
- Visualize relationships using scatter plots and heatmaps  

### Key Observations
- TV and Radio advertising show strong correlation with sales  
- Newspaper advertising has comparatively less impact  

EDA helps in selecting meaningful features and building a better predictive model.

## 🤖 Machine Learning Model

- **Algorithm Used:** Linear Regression  
- **Why Linear Regression?**
  - Sales is a continuous numerical variable  
  - Simple, interpretable, and effective for this problem  
  - Helps understand the impact of each advertising channel  

---

## 📐 Model Evaluation

The model is evaluated using:
- **Mean Squared Error (MSE)** – measures prediction error  
- **R² Score** – indicates how well the model explains sales variability  

An **Actual vs Predicted Sales** plot is used to visually assess model performance.

---

## 📈 Results & Business Insights

- The model is able to predict sales with good accuracy  
- Advertising expenditure on TV and Radio has the highest impact on sales  
- Regression coefficients provide insights into marketing budget allocation  

This project demonstrates how machine learning models can convert raw data into **actionable business insights**.
